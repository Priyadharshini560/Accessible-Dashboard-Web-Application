# Semantic HTML5 & Accessible Component Architecture

An accessible enterprise dashboard starter built with semantic HTML5, CSS, and JavaScript.

## Features
- Semantic `header`, `nav`, `main`, `section`, `article`, `aside`, and `footer`
- Skip link and visible keyboard focus
- Responsive dashboard layout with sidebar
- Accessible data table with caption and scoped headers
- Form labels, fieldset, legend, required fields, and native validation
- Native HTML `dialog` modal
- Mobile navigation toggle with `aria-expanded`

## Local setup
1. Download or clone this repository.
2. Open the folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. No build step or package installation is required.

## First vertical feature slice
The first feature slice is the dashboard overview: users can navigate the dashboard, view summary cards and reports, open a report dialog, and submit feedback through a validated form.

## Validation
Validate `index.html` at https://validator.w3.org/nu/
Resolve any reported errors before submission. A validator result must be checked after upload; do not assume zero errors without running it.
